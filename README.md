# Clone do Spotify 🎵

Este projeto é um **clone do Spotify** focado no **front-end**, contendo uma **landing page** e uma **página de login**, criado com o objetivo de treinar desenvolvimento web e design de interfaces.

---

## 🔹 Tecnologias utilizadas
- HTML  
- CSS  
- JavaScript (apenas interações visuais, sem backend)  
- Font Awesome (ícones)  
- Google Fonts (tipografia Montserrat)

---

## 🔹 Funcionalidades
- **Landing page:**  
  - Layout moderno inspirado no Spotify Premium  
  - Seções de destaque de planos e benefícios  
  - Design responsivo para desktop e mobile  

- **Página de login:**  
  - Formulário de login estilizado  
  - Inputs para usuário e senha  
  - Botão de login com efeito hover  
  - Foco em experiência visual, sem funcionalidade de autenticação
